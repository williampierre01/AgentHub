# Roteiro de aprendizagem

O AgentHub é um único projeto incremental. Cada módulo adicionará capacidades ao mesmo sistema e terminará com exercícios, testes e uma revisão do histórico Git.

## Módulos

| Módulo | Tema | Resultado principal |
|---:|---|---|
| 0 | Ambiente profissional e versões | Ambiente Python isolado e projeto versionado |
| 1 | Fundamentos sólidos de FastAPI | API mínima e fluxo completo de uma requisição |
| 2 | Pydantic e contratos | Entrada, saída e validação tipadas |
| 3 | Arquitetura de APIs | Separação entre routers, services e repositories |
| 4 | Async, concorrência e streaming | Processamento assíncrono e respostas progressivas |
| 5 | PostgreSQL e persistência | Dados persistidos com migrações |
| 6 | Autenticação e segurança | Usuários, tokens e permissões |
| 7 | Testes e observabilidade | Testes, logs, métricas e tratamento de falhas |
| 8 | APIs para LLMs | Serviço de geração desacoplado do provedor |
| 9 | Tool calling | Agente capaz de selecionar e executar ferramentas |
| 10 | Estado e memória | Conversas e execuções persistentes |
| 11 | LangGraph | Workflow agentic explícito e testável |
| 12 | MCP | Integração com servidores e ferramentas MCP |
| 13 | Sistemas multiagente | Agentes especializados e coordenação |
| 14 | Docker e produção | Imagem reproduzível, filas e implantação |
| 15 | Projeto final | AgentHub API integrada |

## Princípios do curso

1. Entender o mecanismo antes de adicionar um framework de abstração.
2. Fazer mudanças pequenas, verificáveis e registradas no Git.
3. Não atualizar Python ou dependências sem avaliar compatibilidade.
4. Escrever testes junto com os comportamentos importantes.
5. Nunca armazenar chaves, tokens ou senhas no repositório.
